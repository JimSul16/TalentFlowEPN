# Base de Conocimiento de TalentFlow

Este directorio almacena el contexto persistente, decisiones arquitectónicas y aprendizajes entre sesiones de desarrollo para los agentes y el equipo.

## Estructura de Registro

Cuando descubras una limitación técnica, un patrón del proyecto o resuelvas un bug recurrente:
1. Registra el contexto, el problema y la solución acordada.
2. Mantén esta información sintetizada para que cualquier agente en una nueva sesión la pueda asimilar rápidamente.
